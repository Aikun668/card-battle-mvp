# 在线 PvP 执行方案

本目录承载“在线双人对战”的第三层执行文档。它的上层产品与架构决策位于 `docs/产品方案/`，现有玩法、历史计划与人机接口文档不在此目录重复维护。

## 文档地图

- `执行总览与契约门禁.md`：实施顺序、阶段依赖与接口冻结门槛。
- [在线PvP接口契约-v1](../../接口契约/在线PvP/在线PvP接口契约-v1.md)：前后端唯一的在线对局 API 契约与请求序列。
- `后端房间与持久化计划.md`：房间、座位凭证、SQLite、共享状态与并发实现。
- `前端在线对战状态机与对接清单.md`：页面状态、轮询、操作映射和契约消费规则。
- `联调验收与部署交付方案.md`：自动化、双端人工验收、部署与回归检查。

## 使用顺序

1. 先确认 `执行总览与契约门禁.md`；
2. 冻结 [在线PvP接口契约-v1](../../接口契约/在线PvP/在线PvP接口契约-v1.md) 并为其建立契约测试；
3. 后端与前端只能在冻结契约范围内分别实施；
4. 最后按 `联调验收与部署交付方案.md` 完成真实双端验收。

任何新增在线 PvP 文档必须放入本目录并在本文件登记；不要把同主题的临时说明、复盘或计划散落到 `docs/` 根目录。
