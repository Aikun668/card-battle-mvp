# 英雄平衡落地：法师血量与战士守护（2026-09-22）

## 背景：为什么现在才敢动数值

连招规划与意图/条件牌/消耗机制落地之后，AI 读数第一次可信；随后做了一轮
"平衡诊断"，把三个英雄的差距拆开，结论如下。

### 诊断结论摘要（2400 局 + 镜像/对位分解）

1. **先手优势 84%（镜像同英雄）**：先手第 1 回合白打 14.5 血（对手 0 盾），
   之后结算锁定、追不动。这是独立的结构问题，英雄数值修不掉——留第二步。
2. **对位真相（先手/后手分解）**：战士先手 90%、战士后手 34%；
   **法师后手 VS 游侠 1%**。先手优势与英雄差距是相乘的。
3. **英雄差距的来源**：战士的有效生命加成 41.2/局（盾 + 铁甲 + 治疗），
   法师 8.0、游侠 5.7；战士进攻效率（输出/能量 1.88）只有别人一半也照赢。

### 杠杆扫描数据（正式量：镜像 300/英雄、对位 400/组，先手对半，HARD）

## 决策

**法师 `max_hp` 24 → 28；战士技能【守护】`skill_value` 8 → 7。**

以基准为准（劣势对位 ≥ 35%、对位区间 40%~60%、无通吃、尽量成环）：

- 三对位 41.2 / 48.0 / 41.2，最大偏差 ±8.8（baseline 是 ±24）；
- 环近似成立：法师略克战士（58.8%）→ 游侠略克战士（52%）→ 游侠克法师（58.8%）；
- 改动最小：两处数值，机制、AI 评分、卡牌、牌组一个字不动；
- 副作用均为正向：法师对局 2.7 → 3.1 回合（不再是被速杀的送分局）、
  镜像先手优势从 84.3% 微降到 82.9%。

### 被否掉的方案（数据在案）

| 方案 | 实测 | 否决理由 |
|---|---|---|
| 削战盾 8→6（单独） | 战VS法 50.0%、战VS游 38.0% | 战士被削过头，游侠对两家通吃 |
| 削战血 32→28（单独） | 43.3% / 46.0% / 24.0% | 法VS游不治（仍 24%），先手优势不降 |
| 法血 28 + 战盾 6 | 35.5% / 38.0% / 39.0% | 战士两头被克（两头都是 35-38%） |
| 法血 28 + 战血 30 | 38.6% / 53.0% / 41.2% | 战士 vs 法师偏到 38.6%，且要动两处 |
| 法血 30（未定稿但外推可知） | — | 法血 28 已把战VS法压到 44.1%，再加 2 点会让战士全面吃亏 |

## 已知遗留（明确留到第二步，不在本次改动里）

1. **先手优势 82.9%（镜像）**：英雄平衡的所有变体都在 82-86%，修不掉它。
   已预演好的解法：后手补偿 +5 血（镜像 50.4%）+ 修"电脑先手第一击不能闪避"
   （enemy 先手方向 91.4% vs player 先手方向 78.9%，差 12 点就是那个强制 pass）。
   **补偿量级要在新数值下重测。**
2. **法VS游 3.1 回合偏短**：法师对游侠仍是速杀节奏，属于"对局长度"问题。
3. **AI 防守乘子**（失血时平方增长）值约 5 个点：单独修会与补偿叠加过度
   （血+7+RISK0 已经压到 40.7%），排最后。
