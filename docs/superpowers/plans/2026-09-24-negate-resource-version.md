# 无懈可击式反制（资源版）：预演与落地（2026-09-24）

## 背景

三国杀扩展线的第三条候选，经历三个阶段：

1. **作为牌**（牌组 +1 张，共 17 张）：净效应 0——机制本身温和；但同批对照实验
   （+1 张白板）发现了**"加牌 = 约 -10 点"的稀释墙**，载体否决了它；
2. **作为资源**（每局一次的场外机会）：不占手牌、不进牌组 → 通过；
3. **落地**：正式化（公开状态 / 契约 / 测试 / AI 评分 / 序列化兼容）。

## 设计

- **反制机会**：双方各自一次；`ParticipantState.negate_available`（默认 True，每局不重置）；
- **触发**：对手打出装备 / 蓄力时，若防守方"机会还在 + 能量 ≥ 1"→ 挂起
  （`PendingAttack.kind = "play"`）；
- **取消**：花 1 点能量、消耗机会 → 效果不落地（装备不进槽、蓄力不回能量）；
- **放行**：效果照常落地；
- **牌的去向（五区守恒）**：装备牌挂起时先记打出者弃牌堆、放行时"升华"进槽——
  任何时刻五个牌区加起来正好是整副牌（由随机对局守恒测试抓住并修正过一版）；
- **AI**：响应池按 `kind` 分派（attack → 闪避；play → 反制 / 放行）；
  反制估值与装备 / 蓄力同档（6 分）。

## 读数（双方 HARD、先手对半、每组 600 局）

| 指标 | 基线 | 反制资源版 | 差 |
|---|---:|---:|---:|
| 战士 VS 法师 | 50.0% | 47.3% | -2.7 |
| 战士 VS 游侠 | 52.5% | 50.9% | -1.6 |
| 法师 VS 游侠 | 40.8% | 42.7% | +1.9 |
| 镜像先手（平均） | 53.0% | 52.6% | -0.4 |

全部落在 ±3 噪声内：劣势方 42.7% ≥ 35% 底线、无通吃、先手优势保持。

## 实现与验收

- `game/models.py`：`ParticipantState.negate_available`、`PendingAttack.kind`；
- `game/battle.py`：`_open_negate_response` / `_negate_pending_play` / `_take_pending_play` /
  `_has_available_negate` / `can_respond_negate`；序列化兼容（旧档按"机会还在"读）；
- `game/public_state.py`：双方公开块带 `negate_available`、`response.kind`、`respond.negate`；
- `game/ai.py`：响应池按 kind 分派、`score_negate`；
- `api_routes.py`：respond 的 action 接受 `negate`；
- **测试**：`tests/test_negate.py` 6 项（挂起 / 取消 / 放行 / 机会一次 / 无能量不挂起 / kind 隔离）
  + 契约测试更新 + 全量 **299 passed**。

## 期间的方法论收获

- **分离变量法**：白板对照（+1 张无效果牌）把"稀释效应"从"机制效应"里剥了出来——
  这是发现"加牌 = -10 点"的关键，也直接催生了"资源版"的解法；
- **预判两次被数据推翻**（反击"可能无害"→ 有毒；反制"可能同构有毒"→ 无害），
  再次确认"先预演、后实现"的纪律价值：整条线共 9 组读数、4 次干净回退，基线全程未受污染。
