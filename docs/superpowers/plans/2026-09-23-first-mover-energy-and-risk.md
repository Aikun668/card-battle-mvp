# 先手优势联合修复：先手首回合限能 + AI 防守乘子归零（2026-09-23）

## 背景

[先手响应窗口修复](2026-09-22-first-turn-response-window.md) 之后座位不对称消除，
但镜像先手胜率仍有 76-78%（玩家先手 77.7% / 电脑先手 76.1%）。诊断结论：
先手优势来自"第 1 个回合白打"（先手 3 能量打满时对手 0 盾、还没出手），
而且**任何单一修正都会因英雄特性而破坏对位**——所以做了一轮联合优化。

### 探索历程（全部数据在案）

| 方案 | 镜像先手胜率 | 对位（战VS法/战VS游/法VS游） | 结论 |
|---|---|---|---|
| 无修正 | 77.7% / 76.1% | 44.0 / 50.7 / 48.0 | 起点 |
| 后手血 +5 | 48.1%（player 方向） | 31.0 / 52.1 / 45.0 | 否：放大强者 |
| 首回合禁攻击 | 65.4% | 39.3 / 53.4 / 32.2 | 否：不足且破坏对位 |
| 先手首回合 2 能量 | 54.2% / 50.7% | 43.4 / 51.5 / 43.0 | 主力方案 |

**勘误**：上一轮实验里"限能会破坏对位（法VS游 → 36.5%）"的结论是**脚本 bug**——
`_run_enemy_actions` 在响应窗口会被反复进入，每次都给电脑把能量压回 2，
等于无限能量。修掉后重测，限能并没有劣化对位。

### AI 防守乘子

`RISK_WEIGHT = 6.0` 让"失血"以平方增长抬高治疗 / 护盾 / 护甲的评分。
但结算是比血量、护盾不计分，**失血本身不改变攻防价值**——它造成的是
"落后方转防守 → 差值不再缩小 → 领先保持到结算 → 必输"的雪球。

## 决策

1. **先手方第 1 个回合只有 2 点能量**（后手正常 3 点）——在 `BattleState.create()`
   里统一设置，两条路径（player 先手 / enemy 先手）共用同一行；
2. **`RISK_WEIGHT` 6.0 → 0.0**——失血不再抬高防守分；"濒死转身防守"改由
   困难模式的威胁预判（`DANGER_PENALTY`：发现玩家下回合可能击杀自己）负责，
   它看的是"下回合会不会被打死"，而不是"现在掉了多少血"。

## 联合实验数据（镜像 300/英雄、对位 400/组，HARD）

| 变体 | 镜像（电脑先手 / 玩家先手） | 对位 |
|---|---|---|
| baseline | 76.1% / 77.7% | 44.0 / 50.7 / 48.0 |
| 限能 | 50.7% / 54.2% | 43.4 / 51.5 / 43.0 |
| 限能 + RISK3 | 52.6% / 55.2% | 46.5 / 50.1 / 44.8 |
| **限能 + RISK0（定稿）** | **52.4% / 55.7%** | **50.0 / 53.0 / 46.2** |

### 被否方案

- **后手血 +5 / +7**：镜像有效（48.1%），但对位劣化（战VS法 → 31.0%）——
  补偿收益按打法分配（速杀型受益最大），会放大强者；
- **首回合禁攻击**：镜像 65.4% 不足，且法VS游 → 32.2%；
- **RISK3**：介于两者之间，没有突出优点；RISK0 的对位最平衡。

## 测试适配（13 处断言，如实记录）

- `make_battle` 脚手架把先手方的首回合能量补回满（中局行为用例不测限能）；
- "新对局属性"用例改为断言 2 点能量；
- 3 个 AI 评分用例改到新契约：治疗按恢复量计价、濒死防守走 HARD 威胁预判、
  铁甲分不随失血漂移；
- 验证"扣 1 费"的用例先给足 3 点能量；
- 顺带修掉一个"电脑开局装长剑"的概率性断言（验收场景 7 的伤害恒为 6×3）。

## 验收记录

真实代码（零补丁，镜像 500/英雄、对位 700/组，先手对半，双方 HARD）：

- **对位**：战VS法 51.0%、战VS游 53.3%、法VS游 46.6%；**劣势方最大数值 46.6%**
  （基准 ≥ 35%），最大偏差 ±3.4——三个英雄互有胜负；
- **镜像**：战士 55.8%、法师 50.6%、游侠 54.8%（平均 **53.7%**，修复前 84.3%）；
  玩家先手方向 59.2 / 50.4 / 50.8%，电脑先手方向 52.0 / 50.8 / 58.8%；
- **测试**：268 passed，连续 25 轮无 flaky。

## 已知遗留

- 镜像先手优势仍有 ~54%（战士与游侠的先手方向约 56-59%）；再往下压属于
  精细打磨，可留到下一轮按"英雄级微调"处理；
- AI 的"留能量反制"细节策略（`DODGE_HOLD_BONUS` 相关探针结论）本轮未动。
